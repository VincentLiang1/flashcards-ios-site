螺旋單字卡

把在 Duolingo 遇到的外語(預設英文;可以打開西班牙文、德文、日文、法文、拉丁文)做成閃卡,用 1、2、3、5、8… 天的間隔每天複習。iPhone App,目前只透過 TestFlight 給家人試用。

可以做什麼

  • 截圖分享進來,點選要的句子,自動補上中文和音標(英文可選 KK 或 IPA)。
  • 每天打開複習到期的卡片:忘記、困難、記得,App 自動安排下次。
  • 選用:貼上自己的 Claude API 金鑰,複習時可以請 Claude 講解、出例句、回答問題。

支援

測試期間有問題,請在 App 裡截圖,選「傳送測試版回饋」。
